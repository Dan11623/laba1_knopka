# Сетевая игра Морской бой (P2P)

Простой и удобный Морской бой для двух игроков по локальной сети. Игра написана на языке Python с использованием стандартной графической библиотеки Tkinter и сетевых сокетов.

## Как это работает (Технологии)

Проект использует гибридный сетевой протокол для автоматического поиска соперника и стабильной игры:

*   UDP Broadcast — используется для поиска игры в локальной сети. Клиент отправляет широковещательный запрос в сеть, а запущенный сервер ловит его и сообщает свой точный IP-адрес. В коде реализован направленный бродкаст (directed broadcast, например 192.168.1.255) для обхода блокировок домашних роутеров.
*   TCP Сокеты — после того как устройства нашли друг друга, они устанавливают прямое надежное соединение. По TCP передаются команды выстрелов (SHOT:) и результатов (RES:). Это гарантирует 100% доставку пакетов без потерь.
*   Неблокирующий режим (Polling) — сетевой сокет переведен в режим setblocking(False). Программа проверяет сеть короткими набегами каждые 100 мс через встроенный таймер Tkinter (root.after), благодаря чему интерфейс игры никогда не зависает.

## Структура проекта

Код разделен на два логических файла:
1.  main.py — чистая точка входа. Запускает приложение и главный цикл окна.
2.  game_logic.py — содержит весь основной класс игры: логические матрицы полей 10х10, случайную генерацию кораблей, отрисовку интерфейса кнопок и обработку сетевых сообщений.

## Запуск из исходного кода

Если вы хотите запустить проект из исходников:

1.  Убедитесь, что у вас установлен Python 3.
2.  Запустите главный файл в консоли:
    ```bash
    python main.py
    ```
